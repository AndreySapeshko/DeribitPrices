# Deribit Prices Service

### Сервис для периодического получения цен криптовалют с биржи Deribit, сохранения их в PostgreSQL и предоставления данных через HTTP API.
[Установка и запуск проекта](#Установка-и-запуск-проекта)

## 📌 Функциональность

**Периодическое (раз в минуту) получение index price:**

- BTC/USD

- ETH/USD

**Сохранение:**

- тикера

- цены

- времени в формате UNIX timestamp

**HTTP API для получения сохранённых данных**

## 🛠 Технологический стек

- Python 3.13

- FastAPI — HTTP API

- SQLAlchemy (async) — работа с БД

- PostgreSQL — хранилище данных

- Celery + Celery Beat — периодические задачи

- Redis — брокер сообщений

- aiohttp — HTTP-клиент для биржи

- pytest / pytest-asyncio — тестирование

- Docker / Docker Compose — контейнеризация

## 🧱 Архитектура

Проект построен по принципам слоистой архитектуры и разделён на логические уровни:
```
app/
 ├── api/          # FastAPI endpoints
 ├── services/     # бизнес-логика
 ├── db/           # модели и репозитории
 ├── workers/      # Celery задачи
 ├── core/         # конфигурация
```
**Ключевые идеи архитектуры**

- Repository pattern — вся работа с БД инкапсулирована

- Service layer — бизнес-логика отделена от инфраструктуры

- Dependency Injection — зависимости передаются явно

- Отсутствие глобального состояния

## 🔌 Расширяемость по биржам и тикерам

Архитектура сервиса изначально спроектирована с учётом расширения:

### ➕ Добавление новой биржи

**Для подключения новой биржи достаточно:**

1. Реализовать новый HTTP-клиент (аналог DeribitClient)

2. Реализовать общий интерфейс получения цен

3. Использовать существующий PriceService

**При этом:**

- логика хранения

- Celery задачи

- API

остаются без изменений.

### ➕ Добавление новых тикеров

Тикеры задаются конфигурационно:
```
TICKERS = {
    "btc_usd": "btc_usd",
    "eth_usd": "eth_usd",
}
```

Добавление нового тикера не требует изменения схемы БД или API.

## 🌐 HTTP API
**Получение всех данных по тикеру**

`GET /prices?ticker=btc_usd`

**Получение последней цены**

`GET /prices/last?ticker=btc_usd`

**Получение цен с фильтрацией по дате**

`GET /prices/range?ticker=btc_usd&ts_from=1700000000&ts_to=1700003600`


**🔴 Во всех методах параметр ticker обязательный.**

Swagger UI доступен по адресу:

http://localhost:8000/docs

## 🗄 Схема БД
```
price_ticks
------------
id          BIGSERIAL PK
ticker      TEXT
price       NUMERIC(30, 18)
ts_unix     BIGINT
```

Индекс:

`(ticker, ts_unix)`

## ⏱ Периодическое получение данных

**Используется Celery Beat, задача выполняется раз в минуту:**

- получает цены с биржи

- сохраняет в БД

## 🧠 Design Decisions

- Async stack (FastAPI, aiohttp, asyncpg) выбран для эффективной работы с I/O

- Celery + Beat — стандартный инструмент для фоновых периодических задач

- UNIX timestamp (BIGINT) используется для простоты фильтрации и отсутствия проблем с таймзонами

- NUMERIC(30,18) выбран для безопасного хранения цен криптовалют

- SQLite не используется в основных тестах — поведение максимально приближено к production

- Явный импорт Celery-задач вместо autodiscover для предсказуемости
